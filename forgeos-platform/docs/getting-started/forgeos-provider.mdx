ForgeOS (usage-billing) is the simplest way to get started with pay-as-you-go model access in ForgeOS.

Instead of managing separate API keys across multiple vendors, you sign in once, add **ForgeOS credits**, and select from available models directly in ForgeOS.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [ForgeOSPass](/getting-started/forgeospass) instead. ForgeOSPass is a separate provider in ForgeOS.

## Why use ForgeOS (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by ForgeOS
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add ForgeOS credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

ForgeOS (usage-billing) is the pay-as-you-go provider in ForgeOS. Add ForgeOS credits, then select **ForgeOS** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **ForgeOS**, and sign in.
- **CLI**: Go to `/settings` and select **ForgeOS** as your provider.

## Credits and usage

- Add **ForgeOS credits** from your [ForgeOS dashboard](https://app.forgeos.bot/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through ForgeOS (usage-billing)
- View usage in ForgeOS Settings → **View Usage**
- Switch organizations in ForgeOS Settings → **Switch Organization**
