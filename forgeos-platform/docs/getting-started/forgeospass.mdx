ForgeOSPass is a low-cost monthly subscription — **$9.99/month** — that offers **2-5x the usage** on popular open coding models compared to standard API rate.

It's completely optional. You don't need ForgeOSPass to use ForgeOS, and you can always use any other provider alongside it.

## How it works

ForgeOSPass is a separate provider in ForgeOS. After subscribing, select **ForgeOSPass** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **ForgeOSPass**, and sign in.

  <img src="/assets/forgeospass/forgeospass-ide-extension.png" alt="ForgeOS IDE extension settings with ForgeOSPass selected as the API Provider" />
</Frame>

- **CLI**: Go to `/settings` and select **ForgeOSPass** as your provider.

## Why ForgeOSPass

Open models have gotten really good. They now reach performance close to proprietary models for coding tasks, and because many providers can serve them competitively, they're usually far cheaper.

However, getting reliable access can be difficult. Providers vary in quality and availability, and standard rate limits can throttle heavy agentic workflows that read files, run commands, and iterate across many turns.

ForgeOSPass solves this by:

- Curating a select group of open models tested and benchmarked for coding agent use
- Offering **2-5x the usage** on popular open coding models compared to standard API rate, so you can run long, complex agent tasks without interruption
- Providing stable access through ForgeOS's infrastructure

<Note>
ForgeOSPass is a separate provider from ForgeOS (usage-billing). You can use both independently — subscribe to ForgeOSPass for 2-5x the usage on popular open coding models compared to standard API rate, or use ForgeOS (usage-billing) for pay-as-you-go access.
</Note>

## Using ForgeOSPass outside of ForgeOS

You can use ForgeOSPass models from your own scripts, apps, or automation through the ForgeOS API. The API uses the same OpenAI-compatible Chat Completions format as the rest of ForgeOS's API.

To get started, create an API key from **Settings > API Keys** in [app.forgeos.bot](https://app.forgeos.bot). For the complete walkthrough, see the [ForgeOS API Getting Started guide](/api/getting-started).

Use the full ForgeOSPass model slug in the `model` field:

```bash
export FORGEOS_API_KEY="your_api_key_here"

curl -X POST https://api.forgeos.bot/api/v1/chat/completions \
  -H "Authorization: Bearer $FORGEOS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "forgeos-pass/qwen3.7-max",
    "messages": [
      {"role": "user", "content": "Write a TypeScript function that validates an email address."}
    ],
    "stream": false
  }'
```

## Usage

ForgeOSPass measures usage against three limits:

- **5-hour rolling window** — your usage within rolling 5-hour period
- **Weekly** — your usage over the calendar week
- **Monthly** — your usage over the calendar month

To check your current usage, visit your [ForgeOS dashboard](https://app.forgeos.bot/dashboard/subscription?personal=true).
